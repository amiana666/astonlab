# First Steps
## Введение
В этом задании ты познакомишься с GIT, Bash, Терминалом Linux, 
а также сделаешь первые шаги в инженерии а аналитике данных.

В ходе выполнения, категорически запрещено списывать, на предстоящей защите проекта все вскроется. 
При этом использовать нейросети и интернет для исследования непонятных тем не запрещено.

## Инструкция
1. Перед выполнением этого проекта убедись что у тебя установлен `WSL`, 
а также `GIT` (В случае если ты на `Windows`). 
Если ты работаешь с `MacOS` либо `Linux` используй для работы `встроенный терминал`.

2. Работать с `GIT` можно только через командную строку. Никаких графических интерфейсов.

3. Перед выполнением проекта склонируй `этот` репозиторий себе на компьютер.

4. Создай ветку `develop` и переключись на неё, всю работу можно вести только на ней.

5. Создай папку `src` если её ещё нету, весь свой код располагай только тут.

6. Если в задании сказано использовать директорию из прошлого задания, используй относительные пути, а не копируй папку.

7. Добавляй все файлы в `GIT` `по ходу` выполнения задания, в конце сделай `git push` на ветку `develop`

8. Все отчеты должны быть оформлены в формате `markdown` (`.md`). 
Все заголовки должны начинаться со `второго` уровня. 
Изображения для отчета должны храниться в папке `img` в корне репозитория (`не в src !!!`). 
За референс можно использовать этот Readme.

### 3. Partitioning and Sorting

    - Папка для сдачи задания: `ex02/`

    - Файлы для сдачи: `partitioner.sh`, `concatenator.sh`

    - Дирректории: `partitions/`, `rebuilt/` 

Поздравляю, у тебя получились `.csv` файлы. Но чего-то не хватает. 
Давай сделаем сортировку, но усложним задание.
Сделаем её через партиционирование и конкатанацию.

Когда у тебя большой набор данных, иногда может быть полезно разбить его на разделы (партиции).
Каждый раздел имеет определенный диапазон ключей. Один из популярных способов разделения — это
разделение по дате. Каждый раздел содержит данные за определенную дату.
---
1. Напиши скрипт под названием `partitioner.sh`, который:
   - принимает на вход результат упражнения 2.
   - формирует на выходе следующую структуру с файлами:
    ```
    partitions/
      └── имя_файла_без_расширения/
          ├── header.csv
          ├── 2026-01/
          │   └── data.csv
          ├── 2026-02/
          │   └── data.csv
          └── ...
    ```
    где имя файла - это название акции.
    
    Скрипт должен быть написан на языке bash и быть исполняемым.

---
2. Напиши скрипт `concatenator.sh`, который пересобирает партиции так чтобы год и месяц шли в убывающем порядке.

```
"2026-05-25"
...
...
"2026-04-30"
...
...
"2025-12-30"
...
...
```

На выходе скрипт должен создать новые файлы с правильной сортировкой в директории `rebuilt/`.

Скрипт должен быть написан на языке bash и быть исполняемым.
